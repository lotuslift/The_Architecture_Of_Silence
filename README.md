## Five-paper kernel and two expositions

This repository presents a bounded, auditable mathematical release by **Anthony Vito Coppa**. It contains five papers that separate local operator algebra, admissibility discipline, central return, finite relational addressing, and conserved transport into distinct jurisdictions. The Clear_Onyx exposition states the computational implementation contract. *The Structure of Survival* supplies the unified synthesis of motion, metric, memory, recognition, physical readout, and continuum return.

Each paper directory contains the compiled PDF, the LaTeX source, its regression checker, and the original SHA-256 manifest. Each exposition directory contains its compiled PDF, LaTeX source, and SHA-256 manifest.

## Central computational statement

The Clear_Onyx kernel generated by the Fibonacci operator and quarter-turn operator spans the full real matrix algebra on the planar carrier, gives every real 2×2 operator a unique four-coordinate normal form, reduces finite operator words exactly, and keeps visible cyclic phase distinct from retained occurrence.

The release is intentionally typed. Numerical coincidence, shared appearance, common address, or common phase does not by itself identify mathematical offices. The papers distinguish what is **certified**, **derived**, **declared**, interpreted, or left open.

## Verify the package

Python 3.10 or later is required. Install the two symbolic and numerical
verification dependencies before running the checkers:

```bash
python -m pip install --requirement requirements.txt
```

```bash
python scripts/verify_release.py
python scripts/run_all_checks.py
```

Or run both:

```bash
make all
```

The GitHub Actions workflow repeats both verification stages on every push and pull request.

## Provenance and checksum policy

The original `.sha256` manifests are retained without modification, including two historical absolute path references. For portable verification of this repository layout, use the root [`SHA256SUMS`](SHA256SUMS) ledger and `scripts/verify_release.py`.

The compiled PDFs are release artifacts. The LaTeX files are the inspectable sources. Regression programs are finite witnesses for the displayed identities and declared finite scans; they do not replace the universal proofs in the papers.

## Scope

This repository publishes the exact mathematical and computational architecture stated in the included works. It does not, merely by packaging those works together, claim physical uniqueness, empirical necessity, or identity between distinct mathematical offices.
